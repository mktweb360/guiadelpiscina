## PARTE 3 — HERRAMIENTAS DISPONIBLES

### 3.1 Barra Web (SiteStripe)

- Aparece automáticamente en la parte superior de Amazon cuando estás logueado
- Permite generar enlaces de afiliado con un clic desde cualquier página de Amazon
- Incluye enlace de texto, enlace de imagen, y código de widget
- **Uso para los blogs:** Herramienta principal para obtener ASINs y generar enlaces rápidamente cuando se crea nuevo contenido

### 3.2 OneLink

- Convierte automáticamente los enlaces de Amazon.es en enlaces para el país del visitante
- Configurado para: Reino Unido, EE.UU., Canadá, Alemania, Francia, Italia, Japón, y 10 países más
- **Estado actual:** La cuenta de España puede vincularse con cuentas de otros países
- **Oportunidad:** Si los blogs reciben tráfico internacional (por tema o por posicionamiento), OneLink permite monetizar esos clics también
- **Prioridad:** Baja por ahora (blogs en español, tráfico nacional), pero activar cuando haya tráfico confirmado de UK/DE/IT

### 3.3 Product Advertising API

- API para acceder al catálogo de Amazon programáticamente
- Permite: buscar productos, obtener precios reales, imágenes oficiales de Amazon, disponibilidad en tiempo real
- **Requisito:** Requiere un mínimo de ventas para mantener el acceso (normalmente 3 ventas en 180 días)
- **Oportunidad enorme:** Con la API activa, se puede automatizar la actualización de precios, imágenes de producto reales (resolviendo el gap identificado en la auditoría), y ASINs
- **Prioridad:** Alta — en cuanto se generen las primeras ventas, solicitar acceso a la API

### 3.4 Creator API (creatorsapi)

- API para creadores de contenido
- Permite gestionar escaparates, listas de productos, y contenido de afiliado programáticamente
- **Aplicabilidad:** Permite construir un sistema automatizado de actualización del catálogo en los blogs

### 3.5 Verificador de enlaces

- Herramienta del portal: `https://afiliados.amazon.es/home/tools/linkchecker`
- Verifica si un enlace de afiliado está correctamente formateado
- **Uso:** Ejecutar antes de cualquier publicación nueva de productos para verificar que los ASINs y el tag están correctamente formados

### 3.6 Generación de IDs de Seguimiento

- Permite crear múltiples tracking IDs distintos
- **Oportunidad:** Crear un tracking ID por sitio (`ctmascota-21`, `fitnessfcl-21`, `emprendedgt-21`, `juguetestm-21`, `guiapiscin-21`) para tener métricas separadas por blog y saber qué blog genera más ventas
- **Actualmente:** Todos los blogs usan el mismo tag `cclaserdepi01-21` — sin visibilidad por sitio

Endpoint base: `https://webservices.amazon.es/paapi5/searchitems`
