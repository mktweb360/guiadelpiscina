## 4. METODOLOGÍA DE TRACKING

### 4.1 Herramientas (sin coste)

| Herramienta | Función | Frecuencia de revisión |
|-------------|---------|----------------------|
| **Google Search Console** | Posiciones reales, impresiones, CTR, cobertura de índice | Semanal |
| **Google Analytics 4** | Tráfico orgánico, comportamiento, conversiones | Semanal |
| **Bing Webmaster Tools** | Posiciones en Bing (20% cuota móvil ES) | Mensual |
| **Google PageSpeed Insights** | Core Web Vitals, LCP, CLS, INP | Tras cambios técnicos |
| **Ahrefs Webmaster Tools (gratuito)** | Backlinks, DR, errores técnicos básicos | Mensual |
| **Ubersuggest (plan gratuito)** | Monitoreo de keywords limitado | Mensual |
| **Chrome + Rich Results Test** | Validación schema markup | Tras cambios de schema |
| **Screaming Frog (500 URLs gratuitas)** | Crawl técnico: broken links, redirects, meta tags | Trimestral |

### 4.2 Métricas Clave por Sitio

**Métricas de adquisición (GSC):**
- Clicks orgánicos totales (semana/mes)
- Impresiones totales
- CTR medio (benchmark: >3% es buen resultado)
- Posición media general
- Posición media de las 20 keywords prioritarias

**Métricas de monetización:**
- Clicks en Amazon Associates (panel Amazon)
- Tasa de conversión de tráfico → click Amazon
- Ingresos por comisión Amazon Associates

**Métricas técnicas:**
- Core Web Vitals: LCP (<2.5s), INP (<200ms), CLS (<0.1)
- Páginas indexadas vs. páginas en sitemap
- Errores de cobertura en GSC
- Errores de schema en Rich Results Test

### 4.3 Hoja de Seguimiento de Posiciones (estructura recomendada)

Para cada sitio, crear una hoja de cálculo con las siguientes columnas:

```
Keyword | URL objetivo | Posición GSC (mes 0) | Posición GSC (mes 1) | Posición GSC (mes 2) | Posición GSC (mes 3) | Variación 0→3 | Clicks/mes | Impresiones/mes | CTR | Estado
```

**Dónde ver posiciones en GSC:**
1. Search Console → Rendimiento → Resultados de búsqueda
2. Filtrar por país: España
3. Exportar CSV mensualmente (primer día hábil de cada mes)
4. En la columna "Consultas", filtrar por las 20 keywords prioritarias de cada sitio
